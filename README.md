# Google Play Store Data Analytics Project

## Project Overview
This project analyzes Google Play Store app data using Python to understand app ratings, reviews, installations, categories, and pricing.

## Objectives
- Clean the dataset.
- Handle duplicate and missing values.
- Perform data analysis.
- Create charts and visualizations.
- Generate business insig hts.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Dataset Collection
2. Data Import
3. Dataset Inspection
4. Data Cleaning
5. Data Transformation
6. Exploratory Data Analysis (EDA)
7. Descriptive Statistical Analysis
8. Data Visualization
9. Business Insight Generation
10. Conclusion and Recommendations

## Data Cleaning
- Removed duplicate records.
- Removed incorrect records.
- Checked missing values.
- Converted data types.
- Created Size_MB column.
- Detected outliers using IQR.

## Data Visualization
- Category-wise app count
- Free vs Paid apps
- Rating distribution
- Top 10 installed apps
- Average rating by category
- Top 10 reviewed apps
- Correlation heatmap

## Business Insights
- Total Apps: 10,357
- Average Rating: 4.19
- Most Common Category: FAMILY
- Most Installed App: Google Play Books
- Most Reviewed App: Facebook
- Free Apps: 9,592
- Paid Apps: 765
- Average App Size: 21.29 MB

## Recommendations
- Improve app quality and user experience.
- Analyze user reviews.
- Provide regular updates.
- Study popular app categories.
- Improve app performance.

## Conclusion
This project helped us understand Google Play Store data through Python-based data cleaning, statistical analysis, EDA, and visualization. Useful business insights were generated from the dataset.
